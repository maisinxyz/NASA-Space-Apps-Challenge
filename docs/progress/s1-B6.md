# s1-B6: Simulator dashboard

## Built
- `/simulate`: storm picker (radio list, total/wettest day/soil wetness/source grid with `weather_source.basis`, "Synthetic hourly profile" note, Recharts hyetograph with replay-time marker), rotation chips (max 3, store `simRotationIds`), A/B selects (store `rotationIds`), Run -> `runSimulation` then poll `getSimulation` every 1 s with a progress bar; `failed` or transport error -> ErrorCard with retry.
- Timeline: play/pause, scrub (minutes from storm start, step = frame step), full replay ~12 s. Space play/pause, arrows scrub (Shift x10); ignored while a control has focus (`lib/keys.ts`).
- View toggle Single/Side by side (aria-pressed + check mark), difference toggle, split-position slider (store `divider`), A/B labels over the canvas.
- HUD A vs B: 7 Metrics rows with unit + basis from `Metrics.basis` (bare days: "derived", not in Metrics.basis), "B vs A" as % less/more (relative). Diff panel: `getDiff` + `diffLegend`, mean change and changed area with `DiffStats.basis`.
- Risk layer offered once a sim exists; insights include timed ones from the evidence bundle.
