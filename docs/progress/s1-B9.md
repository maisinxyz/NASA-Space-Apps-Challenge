# s1-B9: Guided demo, Reset, presenter, offline

## Built
- `lib/tour.ts`: the 8 beats as data (beat, title, route, store patch, durationMs, caption); total 79 s. `lib/tour.test.ts` asserts order, < 90 s, valid keys and routes.
- `components/TourController.tsx` (in the root layout via `components/Providers.tsx`): header "Guided demo" resets the store and starts; non-modal panel with Back / Pause / Skip / Exit (Esc), progress bar, dev-only elapsed time; console prints measured total. Pages fill data-dependent choices during the tour (first field on beat 3, auto-run on beat 4).
- Measured in headless Chrome (dev server, mock): 79.1 s for the full tour, twice; also at 1920x1080 in presenter mode.
- Reset key R (ignored in text inputs): `reset()` + window event `fieldtwin:reset` -> ViewerStage calls `replay()`. Verified on /viewer.
- Presenter mode (header toggle, separate `usePresenter` store so Reset keeps it): 112.5% type, `[data-dev-only]` hidden (mock badges, dev elapsed, scan's dev checkbox); a "mock data" note stays in the header when data is mock (`isMock` or mock extras).
- OFFLINE: `next.config.ts` env `NEXT_PUBLIC_OFFLINE`; client forces local `/mock` files when "1"; header shows "Offline: pre-built data". Unit-tested in `lib/api/client.test.ts`.
- Backup video: `NEXT_PUBLIC_BACKUP_VIDEO_URL` link, else "Backup video: not recorded yet" (tour panel).
