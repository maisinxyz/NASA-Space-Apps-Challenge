## Known gaps

- `PrecomputedSource` requires `data/seed/<site_id>/elevation.tif` to exist — built by `make seed` (Prompt 50).
- Reprojection uses rasterio bilinear; antialias filter for significant downsampling is not yet applied (acceptable for MVP).
- `reproject_and_resample()` does not handle multi-band sources (not needed for DEMs).

## Next prompt must know

- `ElevationGrid.transform` is a 6-tuple: `(x_west, cell_x, 0, y_north, 0, -cell_y)` — GDAL affine origin at top-left corner of top-left pixel.
- `fill_nodata()` raises `ApiError("TERRAIN_COVERAGE_MISSING")` when remaining nodata > 30 % after filling holes ≤ 500 cells.
- `content_hash(bbox, cell_m, source_versions)` → 64-char hex SHA-256.
- `utm_epsg_for_bbox()` picks zone from centre lon/lat; northern hemisphere 326xx, southern 327xx.
- Prompt 30 (HrdemSource) must supply `SourceInfo` and produce an `ElevationGrid` with `model="DTM"` and proper `vertical_datum`.
- Prompt 31 (NasaDemSource chain) uses `get_terrain_source_chain()` (not yet written; stub in BE-01-chain.py once 30 merges).
