# s1-B5: Viewer page

## Built
- `/viewer`: terrain from `?terrain=` / `?site=`, else store, else first site (`lib/useSiteData.ts`, writes siteId/terrainId to the store). `<TwinViewer />` loaded client-only through `components/ViewerStage.tsx` (quality, divider, reducedMotion from `useReducedMotion`, "Height x1.5 exaggerated" label, coarse badge, Reset -> `replay()`).
- Left panel: site name + Pre-built/mock badges, layer toggles with Legend (unit + basis), field list as buttons (keyboard path to the polygons), field details, point readout. Right panel: insights, link to /simulate, data sources.
- Field details: name, area_ha, illustrative crop, "Illustrative (synthetic)" + dev mock badge, mean slope computed client-side from the slope layer PNG inside the polygon (`lib/fieldStats.ts`, labelled derived, approximate). Camera "Focus on field" / "Overview".
- Probe: separate tiny zustand store so pointer moves re-render only the readout.

## Files
app/viewer/page.tsx, components/ViewerStage.tsx, components/twin/{LayerPanel,FieldPanel,ProbeReadout,InsightPanel,Attribution}.tsx, lib/useSiteData.ts, lib/fieldStats.ts (+ test)

## Run
Dev server, open /viewer or /explore -> Open in viewer. Fields need NEXT_PUBLIC_MOCK_EXTRAS=1.

## Gaps
- Fields are R1 mock only; with the flag off the panel says so. R2 per-field summary not in contract: only area (from the mock) and the derived mean slope are shown.
- Mean slope maps grid cells linearly into bbox_wgs84 (grid is really in the projected CRS); fine at ~20 ha.
- Basis choices: lon/lat "derived"; elevation = basis of the terrain's elevation source, "assumed" if none; synthetic field area "assumed".
