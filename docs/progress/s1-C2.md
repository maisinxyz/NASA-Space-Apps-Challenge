# s1-C2: Farm list, cards, About, header, homepage shell

Branch `fe/S1-cesium-globe`. Owner: agent-shell. Nothing committed.

## What was built
- `apps/web/lib/farms.ts`: `FARMS: Farm[]` (8 public research farms, one per country) and `farmById`. Every fact has its source URL in a code comment.
- `apps/web/lib/store.ts`: `farmId: string | null`, `globeView: "globe" | "farm"` in `AppState`; `reset()` returns to the globe with no farm.
- `apps/web/components/globe/GlobeHome.tsx`: homepage body. Loads `Globe` only through `next/dynamic` (`ssr: false`). Overlays: pitch + first-interaction hint (top-left), farm list (right dock), farm card (bottom-left), farm-view bar (Back to globe, Reset view, farm name, "Open simulation" + always-visible "Synthetic storm demo" for the hero, "Explore only: simulation not available for this farm yet" otherwise), `aria-live` status, dev-only tile tier chip (`data-dev-only`). An error boundary plus `onError` switch to the fallback: "The 3D globe could not load", the list, and "Open the offline view" (`/viewer`). Below 768 px the globe is not mounted: list + card + "Best on a larger screen". Escape closes the card; the global Reset key (R) clears the selection and calls `resetView()`.
- `FarmList.tsx` (list of buttons, `aria-pressed`, tier as text), `FarmCard.tsx` (name, operator, country, area with unit when sourced, tier tag, "Approximate location" note, source link `target="_blank" rel="noopener noreferrer"`, "Open twin"; without a globe the hero card links to `/simulate` with the synthetic label).
- `AboutPanel.tsx`: "About" header button + native `<dialog>` (`showModal()`: focus trap, Escape closes) holding the old landing content: How it works, Roadmap with drone/video capture marked "Not available yet".
- `app/page.tsx` now renders `GlobeHome`.
