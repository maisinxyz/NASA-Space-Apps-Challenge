# Prompt 05 — FastAPI skeleton serving fixtures

**Branch:** `be/BE-00-api-skeleton`, stacked on `be/BE-00-fixtures-json`.

## What was built
`services/api/` is a uv project with pinned deps (FastAPI 0.162.5, uvicorn 0.54.0, python-multipart, pyyaml). It needs Python ≥3.12.

```
app/main.py              create_app(settings): CORS (localhost:3000), GZip (≥1 KB), request timing log, error handlers, routers under /api/v1
app/core/config.py       Settings from env: OFFLINE, DATA_DIR, LOG_LEVEL (+ sse_delay_s=0.4, not env)
app/core/errors.py       ApiError(code, message, hint, retryable) → §6.6 body + status map (decision #4).
                         Validation errors → 422 INVALID_INPUT; unknown route → 404 NOT_FOUND; crash → 500 INTERNAL
app/core/logging.py      "GET /path -> 200 in 3.1 ms"
app/core/types.py        ID patterns, request models (SimulationRequest, ValidateRequest, NoteCreate), asset() helper
app/providers/fixtures.py FixtureStore over packages/contracts/fixtures
app/services/<area>.py   health, sites, scans, terrain, weather, crops, simulations, notes  ← swap these for real logic
app/routers/<area>.py    health, sites, scans, terrain, weather, crops, rotations, simulations, notes (thin)
```

- **How mock IDs resolve:**
  - Terrains: `terr_mock_hills | tilted | bowl`.
  - Sites: `site_mock_*`.
  - Scans: `scan_mock_001` (success), `scan_mock_fail` (coverage failure).
  - Simulation: `sim_mock_001`.
  - Any other well-formed ID → 404 `NOT_FOUND`. A malformed ID (wrong prefix) → 422 `INVALID_INPUT`.
- **Storms and rotations:** only the hills terrain has them. Tilted and bowl fall back to the hills lists.
- **`POST /scans`:** validates lat/lon, ≤6 images, JPEG/PNG/WEBP content type (else 415), and the bbox format. It always returns `scan_mock_001`.
- **`POST /simulations`:** checks that the terrain, storm and rotations exist. It returns `200` with the fixture status filtered to the requested rotations.
- **`POST /rotations/validate`:** runs real placeholder checks for unknown crops (→ `valid:false`) and same-family consecutive years. The season window and the returned `rotation` (decision #23) are still TODO for BE-07.
- **Notes:** in-memory, lost on restart.
- **Diff:** `Accept: image/png` (without `application/json`) returns the PNG; anything else returns `DiffStats` JSON. `a == b` → 422.
- **SSE:** a `StreamingResponse` replays the fixture with 0.4 s between events. GZip skips `text/event-stream`.
- **Binary assets:** correct content type and `Cache-Control: public, max-age=31536000, immutable`. Frames are gzipped when the client accepts gzip.

## Tests: `services/api/tests/test_routes.py` (49 pass)
- Every JSON GET returns 200 and validates against `openapi.yaml`, using `fixtures_lib.contract`.
- Every binary GET returns the right content type, cache header and file signature.
- Frames are FTW1 and gzipped. Diff works through `Accept`.
- Unknown IDs return 404 in the error format. Bad input returns 422 in the error format.
- CORS and the `/health` mode work.
- SSE: all events arrive in stage order, and the failure stream ends in `failed`.
- Each POST is tested: scans (with and without images, and a GIF giving 415), simulations (200, and 404 for an unknown storm), validate, notes.
- **Route parity:** FastAPI's own route table must equal the contract's 27 operations exactly.

## How to run
```sh
make dev              # http://localhost:8000/api/v1/health ; docs at /api/v1/docs
OFFLINE=1 make dev    # health reports mode "offline"
make test             # contracts (51) + api (49)
```
I ran it with real uvicorn: `/health`, streaming SSE and the PNG asset all worked.

## Known gaps / notes for BE tracks
- `OFFLINE=1` only changes `/health`.mode. Everything is fixture data anyway. BE-03 and BE-11 must enforce the "curated sites only" rule.
- FastAPI's generated `/api/v1/openapi.json` is **not** the contract. The contract is `packages/contracts/openapi.yaml`.
- Starlette prints a deprecation warning suggesting `httpx2` for TestClient. It's harmless and left as is.
- The API tests import `fixtures_lib` from `packages/contracts` through `sys.path` (see `tests/conftest.py`).
