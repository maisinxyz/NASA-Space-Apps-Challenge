# s1-B2: Design system and honesty components

## Built
- Tokens in `app/globals.css`: semantic CSS vars (paper, surface, surface-2, ink, ink-muted, line, accent, danger, basis-*) mapped via Tailwind 4 `@theme inline`; `.theme-dark` on any container swaps them (dark-safe viewer panels). Diverging diff ramp (`diff-drier/mid/wetter`, same hexes as the viewer), `mock` colour, system font stacks (sans, display serif, mono), global `:focus-visible`, reduced-motion CSS.
- `components/ui/`: BasisChip, MetricValue, Badge, SupportBanner, Card, Tabs, Legend, Skeleton, ErrorCard.
- `/dev/styleguide`: every component in light and `.theme-dark`.

## Files
apps/web/app/globals.css, components/ui/*.tsx, components/ui/{BasisChip,MetricValue}.test.tsx, app/dev/styleguide/page.tsx, vitest.config.mts (oxc JSX automatic runtime)

## Run
`corepack pnpm test`. Styleguide at `/dev/styleguide` (not rendered/checked in a browser).

## Gaps
- BasisChip tooltip is CSS (hover/focus) plus sr-only text; no positioning logic near screen edges.
- Tabs are uncontrolled (`initialId` only).
