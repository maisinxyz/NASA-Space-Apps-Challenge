# Prompt 06 — Next.js scaffold, types, mock/live API client

**Branch:** `fe/FE-00-scaffold`, stacked on `be/BE-00-api-skeleton`.

## What was built
- **`apps/web`:**
  - Next.js **15.5.29** with React **19.1.10**. These are the latest 15.5 / 19.1 patches, chosen over the scaffold's 15.5.4 / 19.1.0 because of the 2025 React Server Components security advisory.
  - App Router, TypeScript strict, Tailwind 4, ESLint, Turbopack, pnpm 12.
- **Libraries:** three, @react-three/fiber 9, @react-three/drei 10, maplibre-gl 6, framer-motion, zustand 5, recharts 3, fast-png. Dev: openapi-typescript, vitest, @types/three.
- **pnpm build scripts:** pnpm 12 blocks them by default. Only `sharp` is approved (`apps/web/pnpm-workspace.yaml`, `allowBuilds`).
- **Scripts:**
  - `pnpm types` writes `lib/api/schema.d.ts`. It's committed. `make types` calls it.
  - `pnpm sync-mocks` copies `packages/contracts/fixtures` into `public/mock/` (gitignored). It runs automatically before `dev` and `build`.
  - Also `test` (vitest), `typecheck`, `lint`.
- **`lib/api/client.ts`:**
  - Covers all 27 contract operations: `getSites, getSite, startScan, getScan, subscribeScanEvents, getTerrain, getLayers, getInsights, getProvenance, getWeatherSummary, getStorms, getCrops, getRotationPresets, validateRotation, runSimulation, getSimulation, getEvidence, getDiff`, plus `diffImageUrl`, `listNotes`, `createNote`, `assetUrl`, `fetchAsset`, `parseSse`, `isMock`, `apiMode`, `apiBase`, `ApiError`.
  - **Mock mode** (the default when `NEXT_PUBLIC_API_MODE` isn't `live`): reads `/mock/...`. Asset paths map `/api/v1/` to `/mock/`. POSTs return fixture responses, and `runSimulation` filters to the requested rotations. `subscribeScanEvents` replays the SSE fixture with timers. `{ mockScenario: "fail" }` or the scan id `scan_mock_fail` replays the coverage failure. Notes are kept in memory.
  - **Live mode:** `fetch` against `NEXT_PUBLIC_API_BASE` (default `http://localhost:8000/api/v1`). Uses `EventSource` for SSE. §6.6 errors become a typed `ApiError` with `code/hint/retryable/status`. A network failure becomes `DATA_SOURCE_UNAVAILABLE`.
- **`lib/api/types.ts`:** short aliases (`Site`, `TerrainPackage`, `Metrics`, …) over the generated types.
- **`lib/decode/heightmap.ts`:** `decodeHeightmap(png, minM, maxM)` uses fast-png and keeps 16 bits. It returns a `Float32Array`, row 0 = north.
- **`lib/decode/ftw1.ts`:** `parseFtw1` returns `{width, height, frameCount, maxDepthMm, frames}`. Also `frameAt` and `byteToDepthMm`. It validates magic, dtype and length.
- **`/dev/api`:** a throwaway page that shows the mode and the output of `getSites()` and `getTerrain()`, with a "mock" badge. The `/` page is a placeholder.
- **Other files:** the `Makefile` `types` target; `make test` now also runs Vitest; the CLAUDE.md Commands section; `apps/web/README.md`.

## Verification
- `pnpm test`: 11 Vitest tests pass.
  - Hills heightmap decodes with 16-bit precision and the package min/max.
  - **The tilted plane decodes as a plane** (0.05 east, 0.02 north, residual < 1 cm).
  - An 8-bit PNG is rejected.
  - **The FTW1 header matches the fixture bytes.**
  - Bad magic and bad length are rejected.
  - Mock client: sites, 404 as `ApiError`, simulation filtering, success and failure SSE replay, `parseSse`.
- `pnpm typecheck`, `pnpm lint`, `pnpm build` are all clean.
- **Live mode with real servers:** I called the client from Node with `NEXT_PUBLIC_API_MODE=live` against uvicorn. getSites, getTerrain, fetchAsset (heightmap), runSimulation, getDiff and the 404 `ApiError` all worked, and CORS allows `localhost:3000`. `next start` served `/`, `/dev/api`, `/mock/sites.json` and the mock heightmap with 200.
- `make test` (all three suites): 51 + 49 + 11 pass.

## Known gaps / next prompts
- I didn't render `/dev/api` in a browser. Only HTTP 200 and the client logic (Node and Vitest) were checked. Open it once with `pnpm dev`.
- No design system, nav or real pages (Prompts 07–08). Geist fonts from the scaffold are still in `layout.tsx`, and FE-00 should replace them.
- **Mock mode is the default** so FE work runs with zero setup. The demo build **must** set `NEXT_PUBLIC_API_MODE=live`, and pages must show the mock badge when `isMock`.
- Diff PNG in live mode: `<img>` and TextureLoader get a PNG automatically through their Accept header, but a plain `fetch` needs `Accept: image/png`.
