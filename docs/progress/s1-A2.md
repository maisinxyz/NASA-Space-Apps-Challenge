# S1-A2 Terrain mesh, normals, imagery drape | 2026-11-12

**Built:** terrain grid in local meters (X east, Z south, Y up), one vertex per cell centre, Y = elevation - min_m in TRUE meters. Exaggeration (default 1.5) is a vertical scale on the scene group, so it never touches the data. Lighting normals come from `normal.png` in the fragment shader. Imagery draped from `texture.jpg`. Soil skirt + ground disc so the site reads as a block.
**Files:** `components/viewer/{geo,assets,material,Scene}.ts(x)`.
**Acceptance:** tilted plane renders as a ramp: PASS (screenshot). Test asserts mesh Y spans exactly 0 .. (max_m - min_m), so exaggeration is a pure scale: PASS.
**Judgement calls:** mesh extent is (width-1)*cell between cell centres (the raster extent is width*cell), so texels and vertices line up exactly. "Coarse imagery" has no contract flag: `isCoarseImagery()` = `resolution_m >= 10` or `source = nasa_gibs` (viewer heuristic); coarse imagery is desaturated so relief shading carries the picture. UI shows the "coarse" badge from that function.
