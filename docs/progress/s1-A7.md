# S1-A7 Water frame playback | 2026-11-12

**Built:** each rotation's FTW1 file becomes ONE 3D texture (256x256x60, about 4 MB). `frameCoord(frame_times_min, timeMin)` gives the fractional frame; linear filtering along the depth axis is the interpolation, so a scrub is one uniform write. Shaded by depth relative to `max_depth_mm` (clear at 0, deepening blue, lower roughness), with a small flow ripple driven by `timeMin` only (deterministic). Low tier halves the grid (max of each 2x2 block).
**Acceptance:** frame lookup unit-tested (exact, interpolated, clamped, uneven times): PASS. Depth 0 shows no water: PASS. Scrubbing smooth: 60 scrubs in headless Chrome with no errors and 60 fps; "no visible hitching" was not judged by eye on a real display.
**Gaps:** real fixtures exist (`sim_mock_001`), so no fake FTW1 was needed beyond the hand-made test buffer.
