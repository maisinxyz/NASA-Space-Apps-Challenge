# S1-A5 Field draping, highlight, picking (R1 mocked) | 2026-11-12

**Built:** `public/mock-extras/fields.json` (5 illustrative fields on `terr_mock_hills`, `data_status: synthetic`, areas computed from the polygons). `loadMockFields(terrain)` returns [] unless `NEXT_PUBLIC_MOCK_EXTRAS=1`. Outlines are draped in the terrain shader from an id raster + an edge-distance raster (smooth lines, no z-fighting, rise with the terraform). Hover tint, selected glow. Pick = ray vs heightfield (march + bisect), then point-in-polygon. Escape deselects.
**Acceptance:** click selects exactly that field (unit test on all 5 + browser clicks in single and both split views): PASS. Empty land deselects: PASS (code + unit test for "no field"). Selection controlled by `selectedFieldId`: PASS.
