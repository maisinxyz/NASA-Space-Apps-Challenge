# FT-B4 — Curated coastal vegetable windows and Current rotation

Implemented ten coastal-BC vegetable windows for cabbage, green bean, beet, carrot, garlic, kale, lettuce, onion, tomato, and zucchini. Other unsupported windows remain null. Each filled window carries a source URL and conversion explanation in trait_sources. The selected dates represent one modeled planting/harvest interval per crop. The source charts publish weeks or months. Calendar edges are used deterministically, with termination represented by the exclusive day after the selected harvest interval. This is a stated modeling convention requiring local review.

Sources include the [Farm to School BC Coastal Crop Planning Chart](https://farmtoschoolbc.ca/wp-content/uploads/sites/3/2022/03/Coastal-BC-Crop-Planning-Chart.pdf), the [Vancouver School Board gardening guide](https://farmtoschoolbc.ca/wp-content/uploads/sites/3/2023/01/web_oct4_gardening_guide.pdf), and the [BC Ministry carrot guide](https://www2.gov.bc.ca/gov/content/industry/agriculture-seafood/agriservice-bc/production-guides/vegetables/carrots). Farm to School BC's chart and the VSB guide supply the harvest intervals missing from the Ministry planting guidance. Existing sourced FAO coefficients and Statistics Canada yields are preserved.

Both BC preset labels are Current rotation. KPU retains its FT-EC2 crop sequence. UBC resolves separate six-year team-defined phases for D3-1 Brassicas, D4-1 Goosefoots, D6-1 Alliums/Legumes, D6-2 Nightshades/Garlic, D7-2 Early Cucurbits, and D5-3 Maya Garden. Rye covers follow the main crops. The Maya plot starts with a representative green bean, reflecting crops described in [UBC Farm's Tal A'xin interview](https://ubcfarm.ubc.ca/saturday-farmers-market-vendor-feature-tal-axin-maya-in-exile-garden/). These are editable starting presets. Explicit request rotations take precedence. Fixed field request scoping so each field resolves its own preset and edits.
