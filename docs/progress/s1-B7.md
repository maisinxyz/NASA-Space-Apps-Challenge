# s1-B7: Rotation Lab, evidence cards, insights

## Built
- `/lab`: presets from `getRotationPresets` with crop names from `getCrops`, bare days per year (derived). "Edit crops" swaps each step's crop; "Check this rotation" calls `validateRotation` (base_rotation_id + edited sequence) and shows valid/not valid plus each warning (plain label, year, message).
- Evidence: for the store `simId`, five-part cards (`components/lab/EvidenceCardView.tsx`) ending with the card's own `support_not_replace` text. No simId -> pointer to /simulate.
- Insights (`components/twin/InsightPanel.tsx`) on /viewer and /simulate: non-blocking side list + numbered pins (`pins`/`onPinSelect`), severity as number, bar shape and text, kind, confidence, body, why it matters, tip. `anchor.at_time_min` insights stay hidden until the timeline reaches them ("N more appear later").

## Files
app/lab/page.tsx, components/lab/EvidenceCardView.tsx (+ test), components/twin/InsightPanel.tsx

## Gaps
- A validated custom rotation (`rot_custom_…`) cannot yet be added to the simulation chips (only presets are listed there).
- Mock validate always returns the same fixture, whatever the edit.
- No R3/R4 features. Severity "n/5" and "minute N" carry no basis chip (ordinal rank and anchor time from the API, not measurements).
