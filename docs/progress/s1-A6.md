# S1-A6 Overlay layers and legends | 2026-11-12

**Built:** the 4 contract layers packed into one RGBA texture + risk per rotation, all colored through one lookup atlas built from the legends (`color_ramp`, `classes`). A toggle is a uniform write. Risk adds a diagonal hatch at index >= 60. Exports for UI: `buildLayerLegends(catalog)`, `RISK_LEGEND`, `diffLegend(stats)` (type `ViewerLegend`), same color stops as the 3D lookup.
**Files:** `components/viewer/{luts,legends,material}.ts`.
**Acceptance:** toggling is instant (no fetch, seen in browser): PASS. Nodata 255 transparent: PASS by construction (lookup alpha 0), not seen on screen because fixtures contain no nodata. `cover_class` uses legend colors: PASS by code; not checked visually.
**Judgement calls:** `color_ramp` is free text in the contract; known names are magma / blues / viridis, anything else falls back to viridis. The risk layer name `"risk"` is viewer-local, not a contract `LayerName`. Risk ramp and hatch threshold are viewer choices.
