# Prompt 03 — Procedural terrain and frame fixtures

**Branch:** `be/BE-00-fixtures-terrain`, stacked on `be/BE-00-contract`. The contract (02) wasn't merged or frozen yet when this ran.

## What was built
- `scripts/make_fixtures_terrain.py` is deterministic (fixed seed, fixed `created_at`). Two runs give byte-identical files. `make fixtures` runs it.
- `packages/contracts/fixtures/terrain/<id>/` for `terr_mock_hills`, `terr_mock_tilted`, `terr_mock_bowl` (256×256, 2 m cells):
  - `heightmap.png` (16-bit), `normal.png`, `texture.jpg` (512×512), `layers/{slope,flow_accumulation,depressions,cover_class}.png`, `terrain.json` (TerrainPackage).
  - **Labelled mock:** every PNG has a `Comment` tEXt chunk saying "FieldTwin MOCK fixture - not real data", and the JPEG has the same comment. Every name ends in "(mock)" and every `quality_flags` contains `mock_data`.
- `packages/contracts/fixtures/simulations/sim_mock_001/`:
  - `frames/{rot_existing,rot_cover,rot_forage}.bin`: FTW1, 60 frames, 256×256. Water gathers in the bowl and valley; peak depth goes existing > cover > forage.
  - `risk/<rot>.png`: relative index 0–100, `255` = masked (water, other, nodata). Normalized to rot_existing's max.
  - **Extra:** `diff/<a>__<b>.png` for all 6 ordered pairs (peak-depth `b − a`, decision #33 encoding), so the API can serve `/diff`.
- `packages/contracts/fixtures_lib/` (importable helpers):
  - `ftw1.py`: `write_ftw1`, `read_ftw1`, `to_bytes`, `from_bytes`, `encode_depths`.
  - `encoding.py`: heightmap, layer, normal and slope encodings. `LAYER_RANGES` are the legend ranges.
  - `terrain.py`: generators, priority-flood depression fill, D8 flow accumulation.
  - `mock_sim.py`: fake frames, risk and diff, plus constants (`STEP_MINUTES=72`, `FRAME_COUNT=60`).
- `packages/contracts/pyproject.toml`: a uv project with pinned deps (numpy, pillow, pyyaml, jsonschema, referencing, pytest). Requires Python ≥3.12, because numpy 2.5 needs it.
- Tests in `packages/contracts/tests/test_terrain_fixtures.py`:
  - heightmap round-trip < 1 cm
  - tilted plane fits a plane with the right slopes
  - bowl depth = 2.00 m
  - cover values ⊂ {0,1,2,3,255}
  - FTW1 round-trip
  - header bytes match §6.4
  - frame files are valid
  - more cover → less water
  - size budget

## How to run
```sh
make fixtures
uv run --project packages/contracts pytest packages/contracts -q
```

## Facts the next prompts need
- **Bbox (all three):** `[-119.6, 49.1, -119.592975, 49.104607]`. Use `terrain.cell_to_lonlat(row, col)` for insight anchors.
- **Layer legend ranges (`encoding.LAYER_RANGES`):**
  - slope 0–30 degrees
  - flow_accumulation 0–5 `log10(cells)`
  - depressions 0–4 m
  - All are linear over bytes 0–254, with 255 = nodata.
- **`terr_mock_hills` features (row, col):**
  - bowl center (70, 190), water where the bowl is deepest, max fill depth 1.72 m
  - bare patch rows 150–175 × cols 30–75
  - road rows 200–203
  - farmyard (215–245, 200–240)
  - 6×6 cover nodata in the NW corner
- **Frames:** peak `max_depth_mm` is about 1719 for existing, 1294 for cover, 1104 for forage. `frame_times_min = i*72`.
- **`terrain.json` details:** `texture.source` is `user_upload`, standing in for a photo. `sources[0].basis` is `assumed`. Fixture asset paths are `/api/v1/terrain/<id>/...`.
