## What was built

### `services/api/app/packaging/__init__.py`

| Symbol | Description |
|---|---|
| `build_terrain_package()` | Writes all assets under `data/packages/<terrain_id>/` and returns `terrain.json` dict |
| `_encode_heightmap()` | 16-bit PNG: `elev = min + (v/65535)*(max-min)` — matches PRD §6.2 and `encoding.py` |
| `_encode_normals()` | RGB normal map: R east (+col), G north (-row), B up — matches `encoding.py` |
| `_copy_and_cap_texture()` | Downscale longest dim to `MAX_TEXTURE_PX = 2048`, save as JPEG q=85 |
| `_build_layers_json()` | LayerCatalog matching `layers.json` schema |
| `_build_terrain_json()` | Full TerrainPackage JSON matching PRD §6.2 schema |
| Size budgets | heightmap 2 MB, layers 2 MB, texture 4 MB — logged as warnings when exceeded |

### `services/api/app/services/terrain.py` (updated)

Resolution order: **real packages first** (`data/packages/<terrain_id>/`), **fixtures second**. Provides `get_terrain()`, `asset_path()`, `get_layers()`, `get_insights()`, `get_provenance()`, `require_terrain()`.
