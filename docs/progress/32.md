## What was built

### `services/api/app/analysis/__init__.py`

Single-module package (all code in `__init__.py`).

| Symbol | Description |
|---|---|
| `analyse(grid)` | Full BE-04 pipeline; returns `(slope_deg, aspect_deg, d8_dir, flow_acc, depress_m, drain_net, stats)` |
| `AnalysisStats` | Dataclass: mean/p90 slope, depression count + largest area/depth/centroid, drainage density, main channel coords, nodata fraction |
| `encode_slope_layer()` | 8-bit [0,30°] → 0-254; 255=nodata (matches `encoding.py` LAYER_RANGES) |
| `encode_flow_acc_layer()` | 8-bit log10(acc) [0,5] → 0-254; 255=nodata |
| `encode_depressions_layer()` | 8-bit [0,4m] → 0-254; 255=nodata |
| `_slope_aspect()` | NumPy gradient; aspect 0=N, 90=E, 180=S, 270=W, −1=flat |
| `_priority_flood()` | Barnes et al. priority-flood depression fill |
| `_d8_direction()` | Esri D8 codes (1/2/4/8/16/32/64/128); vectorised per direction |
| `_flow_accumulation()` | Topological-sort upslope cell count; O(HW log HW) |
| `DRAINAGE_THRESHOLD` | 200 cells (named constant) |

### Algorithm citations

- **Priority-flood:** Barnes, R., Lehman, C., Mulla, D. (2014). Priority-flood: An optimal depression-filling and watershed-labeling algorithm for digital elevation models. *Computers & Geosciences*, 62, pp.117–127. https://doi.org/10.1016/j.cageo.2013.04.024
- **D8 flow direction:** O'Callaghan, J.F., Mark, D.M. (1984). The extraction of drainage networks from digital elevation data. *Computer Vision, Graphics, and Image Processing*, 28(3), pp.323–344.

## Known gaps

- Depression stats use scipy.ndimage.label when available; falls back to BFS. Both give correct counts for synthetic grids.
- `_grid_to_lonlat()` requires rasterio for CRS round-trip; returns (0,0) on ImportError (acceptable until rasterio is reliably installed).
- Numba is not used (not in the declared stack). Performance is O(HW log HW) in pure NumPy; adequate for 512×512 grids.
