# FT-B10 — Custom field analysis

Date: 2026-11-15.

Mounted `POST /field/analyze`. A single closed valid WGS84 ring is checked for self-intersection, finite coordinates and a WGS84 geodesic area of at most 200 ha; its polygon centroid supplies the point used for live data. NASA POWER daily weather and SoilGrids 2.0 soil are fetched for that point. SoilGrids REST is tried first; if unavailable, its documented [WCS](https://docs.isric.org/globaldata/soilgrids/wcs.html) samples the same location. Each response includes source attribution and resolution: [POWER daily API](https://power.larc.nasa.gov/docs/services/api/) is regional, and SoilGrids 250 m layers are modeled, not soil tests. Missing point data gives a retryable `DATA_SOURCE_UNAVAILABLE`, not invented values.

The engine receives location and soil per request; no global site registration or demo-site data is changed. `rotation: preset` uses the existing generic corn/soybean preset and the same pool when selection is omitted, explicitly flagged as not a farm record. User-provided rotations and crop selections are passed through. Flat slope and irrigation availability are assumptions; results are `limited_data`. A canonical JSON hash (sorted object keys, engine version and request) identifies the field and atomic persistent cache; ring start and winding are normalized before the centroid and hash so equivalent rotated or reversed rings reuse an entry; `OFFLINE=1` serves a matching cache only. A bounded per-client in-process limiter returns retryable 429. Its state is per worker, so multi-worker deployments need a shared limiter. The cache contains location and rotation details and should be treated accordingly.

Verification: a live request for the Appendix A UBC-area polygon returned HTTP 200, area 0.283 ha and `limited_data` using actual upstream lookups. Contract validation and deterministic tests cover custom rotations, request isolation, invalid and oversized polygons, source failures, offline cache and rate limit. `uv run --project services/api pytest services/api/tests -q`: 273 passed, one dependency deprecation warning. Tests also cover antimeridian geometry and cache write failure. This live check is subject to upstream availability; no seasonal forecast or field-specific soil test is implied.

WCS samples use the returned raster mask to detect nodata; a valid zero is retained. The [ISRIC layer table](https://docs.isric.org/globaldata/soilgrids/SoilGrids_faqs_01.html) specifies the unit conversion factors. A WCS response lacking a nodata mask may not distinguish an unmasked fill value from zero.

Merged verification: 305 API tests passed. Added typed request validation and seven malformed-input regressions so invalid scenarios, crop lists, and unknown rotation crops are rejected before lookup. The integrated live UBC polygon request returned 200, 0.283 ha, one field, and limited_data in about 18.2 seconds.
